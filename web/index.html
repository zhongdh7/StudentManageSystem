      格式说明

      C 语言结构体与文件布局

      typedef struct Student {
    uint64_t number;    // 8 B   学号
    char     name[32];  // 32 B  姓名（UTF-8 + '\0'）
    float    chinese;   // 4 B   语文
    float    math;      // 4 B   数学
    float    english;   // 4 B   英语
                        // 4 B   对齐填充
};                      // 56 B / 条

      导出文件与 C 程序的 fwrite(stu, sizeof(Student), 1, fp) 完全一致，可直接替换 data/student.txt。
