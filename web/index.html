      常见问题

      第一次使用最容易遇到的几个问题

      网页会直接修改 C 程序的文件吗？

      不会。网页运行在浏览器中，只能通过导入 / 导出文件交换数据；需要手动把导出的 student.txt 放回 data/ 目录。

      数据保存在哪里？会丢吗？

      保存在当前浏览器的 localStorage 中，刷新不会丢失；清除浏览器站点数据会丢失，建议定期导出备份。

      为什么导入时有些记录被跳过？

      网页会校验学号唯一、姓名不超过 31 个 UTF-8 字节、成绩在 0–100 之间。不符合规则的记录会被跳过并在导入弹窗中列出，导入前建议先备份。

      怎么换电脑或换浏览器？

      在旧环境导出 JSON 或 student.txt，在新环境中导入即可；也可以把 student.txt 交给 C 程序继续使用。
